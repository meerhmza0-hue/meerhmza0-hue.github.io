## Free hosting — recommended: GitHub Pages ($0, forever)

Why: free, HTTPS included, no ads, no expiry, and a GitHub profile itself looks good to security hiring managers.
Your URL will be `https://meerhmza0-hue.github.io`.

1. Sign in to your GitHub account (`meerhmza0-hue`).
2. Click **New repository** → name it exactly `meerhmza0-hue.github.io` → **Public** → Create.
3. On the new repo page click **uploading an existing file**, drag in `index.html`, `styles.css`, `script.js` and `README.md` → **Commit changes**.
4. Go to **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save.
5. Wait ~1 minute, then open `https://meerhmza0-hue.github.io`.

Updating later: edit the file on GitHub (pencil icon) or re-upload it — the site redeploys automatically.

add it under GitHub **Settings → Pages → Custom domain**. Not required.
