## Featured project

**[Windows Logs Gap Assessment: AI Skill](https://github.com/meerhmza0-hue/windows-logs-gap-assessment-skill)**
Scores the Windows telemetry an organization collects today against 52 sub-categories and shows how much coverage
it would gain by enabling more logs. It runs in two modes, native Windows logs and Sysmon value, and produces a
two-sheet Excel report with before and after coverage scores.
