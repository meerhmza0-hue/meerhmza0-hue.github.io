04. Projects & AI

        

          

            
Featured · Open source

            
Windows Logs Gap Assessment — AI Skill

            

              Most Windows estates forward Security, System and Application logs and assume they're covered. In practice,
              visibility often hinges on settings that are easy to miss: command-line capture for 4688, SACLs for object
              access, and Operational channels like PowerShell, WMI-Activity and DNS-Client. This AI skill makes those gaps
              measurable.
            

            
    
              
  • Takes a SIEM export (sourcetypes + EventCodes) and maps what you actually ingest to 52 telemetry sub-categories.
    • 
              
  • Scores each as Full / Partial / None, recommends the logs to enable, and shows coverage before vs after as one number management can track.
    • 
              
  • Two modes: Windows Logs Gap Assessment (native audit policy & Operational channels) and Sysmon Value Assessment (is Sysmon worth it, and which event IDs first).
    • 
              
  • Produces a formula-driven, two-sheet Excel report, checked for errors before delivery.
    •

AI in my security work

        

          
Building AI skills
Packaging repeatable security analysis, like log gap assessments, as AI skills with a fixed methodology so results are consistent and auditable rather than ad hoc.

          
Agentic automation
Exploring AI agents for security tooling and workflow automation, from data pipelines to small internal tools built and iterated quickly.
